## Featured Flagship Systems

### 1. Enterprise Employee Management & Payroll System
- **Core Stack**: PHP, MySQL (3NF Normalized), HTML5, CSS3
- **Features**: Biometric Kiosk Attendance (Time-In/Time-Out), automated payroll calculation with deduction algorithms (SSS, PhilHealth, Pag-IBIG), administrative role-based access control (RBAC), and transactional report generation.

### 2. Mythic Gambit: Turn-Based Tactical Game Engine
- **Core Stack**: HTML5 Canvas (2D & Isometric Projection), Web Audio API Synthesizer
- **Features**: Custom multi-perspective camera angles (Tactical Grid, Perspective, Isometric), minimax AI adversary with alpha-beta pruning, dynamic sound effects generator, and fantasy tactical chess simulation.

### 3. Sacred Luxury E-Commerce & Inventory Management Platform (TarotKnight / SmartShop)
- **Core Stack**: JavaScript, LocalStorage State Machine, PayMongo Integration
- **Features**: Real-time product search and category filtering, atomic cart decrementing to prevent overselling race conditions, order tracking lifecycle, and responsive mobile-first commerce UI.

### 4. Interactive Business Intelligence & Sales Analytics Dashboard
- **Core Stack**: JavaScript Data Pipelines, HTML5 Canvas Charts
- **Features**: 50-transaction realistic dataset exploration, monthly revenue breakdown, payment method distribution, and dynamic CSV/Excel dataset exports.

### 5. Arduino IoT Smart Soil Moisture & Plant Monitoring System
- **Core Stack**: Arduino C++, Three.js 3D Interactive Plant Visualization
- **Features**: Simulated capacitive soil sensor data stream, relay pump activation thresholds, 3D leaf moisture deformation shaders, and serial monitor telemetry.

### 6. Simulated IT Job Interview: 12-Point Video Defense
- **Asset**: `assets/video/mock-interview.mp4` with WebVTT closed captions (`assets/video/mock-interview.vtt`)
- **Features**: Embedded HTML5 video player with speed controls (0.75x–1.5x), pop-out launcher, offline download, and complete interactive 12-question technical defense transcript.

## Local Development & Running

### Option 1: Native PowerShell Server (Includes HTTP 206 Video Streaming)
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Open [http://localhost:8080](http://localhost:8080) in your web browser.

### Option 2: Node.js Static Server
```bash
npx serve .
```

## Repository Hygiene & Standards

- **Semantic HTML5 & Accessibility**: Fully tagged ARIA landmarks, `skip-to-content` navigation, and `@media (prefers-reduced-motion)` engine pausing.
- **SEO & Social Sharing**: Integrated Open Graph, Twitter Cards, Schema.org Person JSON-LD, `robots.txt`, and XML Sitemap.
- **Security Hardening**: Subresource Integrity (SRI) on CDN stylesheets, explicit `rel="noopener noreferrer"` across all external links.
- **Asset Optimization**: High-quality compressed imagery with `loading="lazy"` and `decoding="async"` attributes.
