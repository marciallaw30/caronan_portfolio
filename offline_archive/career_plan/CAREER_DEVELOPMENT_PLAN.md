# IT Career Development Plan
**Student Guidelines Step 23 (Pages 7, 11)**

- **Target Position**: Junior Full-Stack Web Developer / Junior Database Engineer
- **Target IT Field**: Web Application Engineering, Enterprise Database Systems, Cloud Infrastructure
- **Current Skills**: JavaScript (ES6+), HTML5/CSS3, Python, MySQL, Git, Technical Troubleshooting
- **Skills to Improve**: Advanced Cloud Architecture (AWS/Azure), CI/CD Automation, Unit Testing Suites
- **Technologies to Learn**: Docker, Kubernetes, Next.js, TypeScript, PostgreSQL Advanced Indexing
- **Certifications to Consider**:
  - AWS Certified Cloud Practitioner
  - Oracle Certified Associate (MySQL Database Administrator)
  - CompTIA Security+

### 6-Month Professional Goal
Secure an entry-level position as a Junior Software Engineer or Junior IT Support Specialist in a reputable technology company. Complete onboarding, master internal development pipelines, and earn the AWS Certified Cloud Practitioner credential.

### 1-Year Professional Goal
Contribute independently to core enterprise web modules, optimize database query execution plans for production workloads, and assume responsibility for CI/CD automated deployment pipelines.

### 3-Year Professional Goal
Attain a Mid-Level Full-Stack Software Engineer position. Lead technical feature development, mentor incoming junior developers, and design highly available cloud infrastructure serving enterprise clients.
