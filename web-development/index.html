Systems Engineering

Relational Database & 3NF Schema Architecture

Designed with Third Normal Form (3NF) relational integrity to guarantee zero data redundancy, audit-proof payroll histories, and instantaneous kiosk lookups.

employees
PRIMARY ENTITY

Core personnel ledger storing biometric IDs, encrypted passwords, government benefit numbers, and RBAC privileges.

  • ● id (INT, PK, AUTO_INCREMENT)
  • ● employeeNo (VARCHAR, UNIQUE)
  • ● password (VARCHAR 255 - Bcrypt)
  • ● firstName, lastName, middleName
  • ● sssNumber, pagibigNumber, tinNumber
  • ● philhealthNumber, bankAccount
  • ● accountType (ENUM: admin, employee)
attendance
TRANSACTIONAL

Time clock punch logs recorded from touchscreen terminals with automatic late and overtime detection.

  • ● id (INT, PK, AUTO_INCREMENT)
  • ● employeeNo (FK -> employees.employeeNo)
  • ● date (DATE)
  • ● time_in (TIME)
  • ● time_out (TIME)
  • ● working_hours (DECIMAL 5,2)
  • ● late_minutes (INT)
  • ● overtime_hours (DECIMAL 5,2)
payroll
FINANCIAL AUDIT

Audited compensation records calculating 15-day gross wages, statutory contributions, and net disbursals.

  • ● id (INT, PK, AUTO_INCREMENT)
  • ● employeeNo (FK -> employees.employeeNo)
  • ● pay_period_start, pay_period_end
  • ● ratePerHour, hoursWorked, regular_days
  • ● grossPay (DECIMAL 10,2)
  • ● total_deductions (DECIMAL 10,2)
  • ● netPay (DECIMAL 10,2)
  • ● payDate, benefitsData (JSON)
